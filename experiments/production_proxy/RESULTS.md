# 油气检索评测 v2：实测结果与适用范围

在 112 道公开资料测试题上，混合检索相对适配分块后的纯向量，前 5 块已标注证据覆盖率提高 **15.62 个百分点**；相对 BM25 单路为 **-16.07 个百分点**。因此本轮支持“混合优于当前纯向量基线”，不支持“混合最优”。

这里评估的是原文证据覆盖，不是回答准确率。全部结果来自本地索引与实际 API 调用；没有按目标分数调整题目。未经专家确认的金标、OCR 与出题方式仍会影响结果。

## 数据规模

- 40 份公开油气报告的 758 个可用 OCR 导出页；8 份报告有页码缺口。
- 20 份报告出题：60 个基础事实、直接问法与改写、20 个两部分问题，共 140 题。
- 50 条模拟行政归档记录、80 个功能边界问题，与公开题分开。
- 总计 220 题；开发 44、测试 176。测试公开题 112，来自 16 份来源报告。
- 题目与源文字符证据在看分数前冻结；按来源系列分组。相同事实改写不是独立样本。
- 来源：[FORCE / Zenodo](https://zenodo.org/records/10775273)。英语公开资料，不等同于中石油业务数据、中文评测或客户使用日志。

| 方法 | 题数 | 证据覆盖 Recall@5 | 全证据齐全@5 | 候选 Recall@100 |

前 5 块与前 100 候选是不同指标。混合候选为向量 50＋BM25 50 后去重，单路最多 100；混合并不包含单路的全部 Top100。

同一原文位置的完整证据被覆盖才记分，可合并相邻块覆盖；同一文档内命中其他位置不算正确。这个定义比“命中任意相关页”严格，但由于未穷尽语义等价证据，应称为已标注证据覆盖率，不能包装成真实线上绝对召回率。

## 配对不确定性

- 适配 token 分块＋向量 相对 整页向量（截断诊断）：+3.12 pp，来源组 bootstrap 95% 区间 [-5.80, 12.95] pp；12 改善、10 退步、90 不变。
- 适配 token 分块＋向量 相对 原 1,000 字符分块＋向量：+3.12 pp，来源组 bootstrap 95% 区间 [-3.12, 9.82] pp；8 改善、5 退步、99 不变。
- 适配分块＋混合 RRF 相对 适配 token 分块＋向量：+15.62 pp，来源组 bootstrap 95% 区间 [9.38, 23.66] pp；20 改善、1 退步、91 不变。
- 适配分块＋混合 RRF 相对 适配分块＋BM25：-16.07 pp，来源组 bootstrap 95% 区间 [-29.02, -2.68] pp；7 改善、29 退步、76 不变。

重排子集配对结果：

- 混合相对 适配 token 分块＋向量：+9.38 pp，95% 区间 [1.56, 18.75] pp，32 题 / 16 个来源组。
- 混合相对 适配分块＋BM25：+0.00 pp，95% 区间 [0.00, 0.00] pp，32 题 / 16 个来源组。

区间只描述当前来源样本的波动，不消除出题偏差或金标遗漏。

## 分块与向量化

- 整页：808 块，超过 256 token 的 406 块，最大 1667 token。
- 原 1,000 字符：1369 块，超过 256 token 的 289 块，最大 876 token。
- 适配 token：1584 块，超过 256 token 的 0 块，最大 256 token。

模型与原项目一致：all-MiniLM-L6-v2，384 维。适配分块把标题和特殊 token 计入上限，重叠 32 token。向量实际生成并缓存在本地；检索用精确归一化点积，与归一化向量 L2 排序等价。不是只用 BM25 假装混合检索。

分块对照改变了长度、重叠和候选粒度，因此不能把全部变化单独归因于“消除截断”。不同大小块的 TopK 文本预算也不同；最公平的混合与单路比较使用相同 token 分块。

这是显式元数据条件下的模拟功能检查。允许角色、站点和 as-of 日期是输入，未对接真实登录态，未实现自然语言日期解析。40 道有答案的模拟测试题各方法均为 100% 覆盖，说明模板检查容易，不能把它们并入公开题来提高总分。

8 道库内无答案测试题仍全部返回了候选。检索到文本不等于能回答；本轮没有回答生成或可靠拒答器，所以不报告拒答准确率。

## 对改进方向与简历的建议

优先补齐编号归一化和来源/时间约束，再在新的独立留出集上比较 BM25＋重排与混合＋重排。本轮已经看过测试结果，不应用同一套题调出更好分数后继续称为无偏测试。

当前可据实描述：构建 220 条油气领域公开与模拟评测问题，实现 token 长度感知分块、BM25 与向量混合检索及消融对照；在 112 条公开资料测试问题上，第一阶段 Evidence Recall@5 由 45.09% 提升至 60.71%（+15.62 pp），同时识别出 BM25 单路更优的场景。

这些是本地复现实验的结果。是否归入实习职责，应与实际承担工作一致；不能写成客户已上线的效果、专家验收结论或真实生产召回率。
